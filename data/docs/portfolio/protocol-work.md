# Protocol Work

## Nunchi.trade

At Nunchi.trade, Bhargav built an on-chain CLOB matching engine for perpetuals, including matching, Clearing House settlement, risk engine, and liquidation flows with Pyth and Stork oracle integration.

He built a real-time on-chain indexer using WebSockets to stream and process contract events, enabling low-latency updates for positions, orders, and liquidation triggers.

He shipped an AI-native CLI that lets autonomous agents execute liquidation and TP/SL jobs against live positions.

He developed an on-chain agent marketplace using ERC-8004 and ERC-8183 where agents register for protocol jobs, complete them, and submit proof-of-completion to claim incentives.

He worked with Quantstamp and Zellic on external audits and owned the audit lifecycle: triaging findings, applying fixes, coordinating review, and securing contracts with Slither and Trail of Bits tooling.

## Novastro

At Novastro, Bhargav developed an RWA tokenization platform for real estate using ERC-3643 with on-chain compliance and identity registry for token issuance.

He architected and deployed a prediction market protocol on Polygon mainnet with cross-protocol yield generation through Aave and Stader.

He developed the Hatchy.fun token launchpad on Solana using Rust and smart contracts built with the Anchor framework.

## Xalts

At Xalts, Bhargav implemented account abstraction using ERC-4337 with paymaster integration for EVM chains including Avalanche subnet and Hyperledger Besu.

He developed in-house account abstraction infrastructure with Skandha bundlers, managed infrastructure for blockchain nodes and bundlers, and architected smart contracts for asset tokenization for financial institutions.

## Oddz

At Oddz, Bhargav led smart contract development for Oddz protocol, an options trading platform with concentrated liquidity similar to Uniswap V3 for capital-efficient risk management, staking, and liquidity provisioning.

Oddz contracts were deployed on Avalanche and BNB Chain mainnets.

He researched derivative trading in crypto, built yield generation mechanisms, developed staking for liquidity providers and ODDZ token holders, and built automation for options protocol workflows including expiry handling, staking reward distribution, and dynamic risk adjustments using Chainlink Keepers and Gelato.
